# 展示仓库文件清单

本仓库使用 `vat_rag_agent` 作为唯一源码目录，不复制历史版本或旁支工程。清单按当前网页运行和工程审查的必要性制定。

## 纳入

| 路径 | 用途与审查结论 |
|---|---|
| `src/tax_rag/**` | Flask 网页、对话编排、检索、引用校验、计算、存储和构建代码。已扫描本地绝对路径、联系方式和凭据模式。 |
| `tests/**` | 自动化回归与模拟数据。测试中的密钥样式均为明确的 `test-*` 占位值，不是真实凭据。 |
| `scripts/start_web.ps1`、`scripts/stop_web.ps1` | 本机网页启动与按进程身份停止入口。 |
| `config/app.toml`、`p2b.toml`、`retrieval.toml`、`runtime.toml` | 当前网页的本地存储路径、模型、检索和运行参数。路径均为相对路径，不包含本机绝对目录。 |
| `config/system_prompt_web_v1.txt`、`cloud_notice_session_v4.txt` | 当前回答约束与实际云端传输告知。 |
| `config/query_normalization_v1.json`、`scope_topics_v2.json` | 当前确定性查询计划与主题范围路由。 |
| `pyproject.toml`、`requirements-p2b.in`、`requirements-p2b.lock.txt` | Python 包定义与依赖版本。 |
| `README.md`、`docs/架构与复现说明.md`、`docs/评估摘要.md` | 招聘方说明、技术路径和评估口径。 |
| `.gitignore`、`.env.example` | 默认拒绝未审查数据文件，列出密钥变量名但不提供密钥。 |

## 不纳入

- `data/` 下的法规原件、副本、SQLite 数据库、Chroma 向量目录、运行时密钥、聊天记录和会话数据库。
- `artifacts/` 下的完整评测输入与输出、原始模型回答、检索轨迹、运行日志、授权记录及历史阶段工件。
- `evals/` 中的完整内部 40 场景题集和答案预期。
- 安装生成的 `*.egg-info/` 元数据和 Python 缓存。
- 历史提示词、过时告知文案、旧配置、知识库来源清单和内部审批文件。
- 项目管理根的原始资料、历史归档、工作状态备份及用户个人资料。

评估仅在文档中给出必要的聚合结果和评审边界。证据原件保留在本地项目内部，不随展示仓库分发。
